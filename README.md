# thescienceoftattooing.com

Source for The Science of Tattooing website: a static, SEO-ready site that replaces the old Wix site and is hosted on Firebase Hosting.

- **Firebase URL (live):** https://thescienceoftattooing.web.app/
- **Custom domain:** https://www.thescienceoftattooing.com/ (see [Domain cutover](#domain-cutover) for status)
- **Learning app:** https://the-science-of-tattooing-dfec8.web.app/ (separate project; this site links to it)

## What has been done

The site was rebuilt from scratch and moved off Wix.

- **New static site.** Plain HTML and CSS, no framework. Every page is generated by one Python script, `build.py`, so the header, footer and SEO tags stay consistent.
- **New page structure.** Home, Ink ingredients (`/ink/`), Book (`/book/`), App (`/app/`), For regulators (`/regulators/`), About (`/about/`), Contact (`/contact/`) and a 404 page.
- **Design.** Built from The Science of Tattooing design system: one stylesheet (`styles.css`), light and dark mode, SVG logo and favicon, a 1200×630 share image.
- **SEO.**
  - A unique title and meta description on every page
  - Canonical URLs, Open Graph and Twitter card tags
  - Schema.org JSON-LD: EducationalOrganization, WebSite, Person (Hannah Wolf), Book, WebApplication, FAQPage, BreadcrumbList
  - `sitemap.xml` and `robots.txt`
  - Semantic headings, alt text and a skip link
- **Speed.** No JavaScript frameworks, the YouTube video loads only on click, and fonts use `display=swap`.
- **Old Wix URLs redirected.** 301 redirects in `firebase.json` send the old Wix addresses to their new pages so existing links and search rankings carry over (table below).
- **Book.** The book page links to Amazon; the site has no cart or checkout.

## How the move to Firebase Hosting works

The site is a second Hosting site inside the same Firebase project as the learning app.

| | |
|---|---|
| Firebase project | `the-science-of-tattooing-dfec8` |
| Hosting site | `thescienceoftattooing` |
| Served folder | `public/` |
| Config | `firebase.json` |

`firebase.json` sets:

- `cleanUrls` and `trailingSlash`, so pages are served as `/ink/`, `/book/` and so on
- Cache headers for CSS, PNG and SVG files (7 days)
- `X-Content-Type-Options: nosniff` and a `Referrer-Policy` header on every response
- These redirects:

| Old URL | Goes to | Type |
|---|---|---|
| `/meet-the-team` | `/about/` | 301 |
| `/store`, `/shop` | `/book/` | 301 |
| `/artistsubmission` | `/contact/` | 301 |
| `/blog`, `/post/**` | `/` | 301 |
| `/play` | the learning app | 302 |

### Domain cutover

The domain is registered at GoDaddy, and its DNS is managed there. As of November 18, 2026 the new site is live at the Firebase URL above, while `www.thescienceoftattooing.com` was still serving the old Wix site. To finish the cutover:

1. Firebase console → Hosting → `thescienceoftattooing` site → **Add custom domain** → `www.thescienceoftattooing.com` (and the bare domain, redirecting to www).
2. Add the DNS records Firebase shows to the domain's DNS at GoDaddy.
3. Wait for Firebase to verify the domain and issue the SSL certificate.
4. In Google Search Console, add the domain and submit `https://www.thescienceoftattooing.com/sitemap.xml`.

## Editing and deploying

Requires Python 3 and the [Firebase CLI](https://firebase.google.com/docs/cli).

1. Edit text, links or page content in `build.py` (site-wide settings are in the CONFIG block at the top).
2. Rebuild the pages:
   ```
   python3 build.py
   ```
3. Deploy:
   ```
   firebase login
   firebase deploy --only hosting --project the-science-of-tattooing-dfec8
   ```
4. Commit and push the changes to this repository.

Edit `build.py`, not the HTML files in `public/`; the next build overwrites them.
